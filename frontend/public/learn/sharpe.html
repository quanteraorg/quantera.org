Sharpe and Sortino ratios

Advanced · Quant

The idea

The Sharpe ratio measures return per unit of risk. It answers: was the extra return worth the extra volatility?

How it works

  • Sharpe = (portfolio return − risk-free rate) ÷ volatility.
  • The Sortino ratio is similar but only counts downside volatility, since upside swings are welcome.
  • Higher is better; above 1 is generally considered good over long periods.

Worked example

Fund A: 12% return, 20% volatility. Fund B: 9% return, 8% volatility. Risk-free 4%. Sharpe A = 0.40; Sharpe B = 0.63. B delivered more return for the risk taken.

Common mistakes

  • Comparing Sharpe ratios measured over different periods.
  • Trusting a high Sharpe from a short or calm period.

Key takeaways

  • Sharpe = excess return ÷ volatility.
  • Sortino focuses on downside risk.
  • Use it to compare risk-adjusted performance.
