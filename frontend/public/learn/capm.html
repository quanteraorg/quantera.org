Risk, beta and expected return

Intermediate · Investing

The idea

Beta measures how much a stock tends to move with the overall market. The Capital Asset Pricing Model (CAPM) uses beta to estimate the return investors should expect for taking that risk.

How it works

  • Beta 1 = moves with the market; 1.5 = about 50% bigger moves; 0.5 = about half.
  • Expected return = risk-free rate + beta × (market return − risk-free rate).
  • The extra return over the risk-free rate is compensation for market risk.

Worked example

Risk-free rate 4%, market expected to return 9% (a 5% premium). A stock with beta 1.4: 4% + 1.4 × 5% = 11% expected return.

Common mistakes

  • Treating beta as total risk — it ignores company-specific risk.
  • Assuming beta is stable; it changes as businesses change.

Key takeaways

  • Beta = sensitivity to the market.
  • Higher beta → higher required return.
  • CAPM is a simple model, not a forecast.
